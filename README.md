# Radar BORA

Radar público de legislación y normativa nueva del Boletín Oficial de la República Argentina.

Incluye leyes, decretos, decisiones administrativas, resoluciones, disposiciones, circulares, comunicaciones y acordadas. Excluye avisos societarios, judiciales, licitaciones, remates y publicaciones no normativas.

La actualización automática se ejecuta todos los días a las 08:00 de Argentina.
